# RCSprints website

Static site for GitHub Pages. Upload everything in this folder to the root of your repo.

Files
- `index.html`, `style.css`, `script.js`: the site
- `config.js`: your published settings (home design, photos, prints, materials)
- `assets/`: logo and school photo
- `.nojekyll`: tells GitHub Pages to serve the files as-is

Updating the live site
1. Open the site, go to Admin, and make your changes.
2. In "Publish your changes" click "Copy settings for GitHub".
3. On GitHub open `config.js`, click the pencil icon, select everything, paste, and commit.
